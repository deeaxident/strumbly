# Strumbly

> **Strumbly is the easiest, simplest to use online guitar tuner with a microphone feature**

🔗 **Live Demo:** strumbly.io

## Overview
Strumbly focuses on ease of use and simplicity. Pick a tuning and a capo position, or simply pick a song you're trying to play and let the AI search show you what tuning you need. Then either listen to each string and adjust your guitar or use the microphone feature and let strumbly show you whether a string is too low or too high.

## Getting Started

### Prerequisites
Make sure you have [Bun](https://bun.sh) (or Node.js) installed on your machine.

### Local Installation
1. **Clone the repository:**
   ```bash
   git clone https://github.com
   cd strumbly
   ```

2. **Install dependencies:**
   ```bash
   bun install
   ```

3. **Set up environment variables (if applicable):**
   Create a `.env` file in the root directory and add any required keys.

4. **Start the development server:**
   ```bash
   bun run dev
   ```

5. **Run tests:**
   ```bash
   bun test
   ```
