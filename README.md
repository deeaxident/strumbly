# Strumbly

Build a beautiful, dark-themed responsive web app called 'StringTune'. It needs a clean circular dial in the center. Give it a button that says 'Start Microphone'. When active, simulate a musical needle moving left or right depending on the note, showing if a guitar string is 'Too Low', 'In Tune' (turn green), or 'Too High'. Add an instructions panel on the side for beginners
